# Журнал решений — вариант М

| № | шаг | решение | обоснование |
|---|---|---|---|
| 1 | очистка | «?», «нет данных», «НЕИЗВЕСТНО» → NaN во всех текстовых столбцах | это служебные отметки об отсутствии ответа, а не категории |
| 2 | очистка | 8 столбцов, где числа записаны текстом (рейтинги, минуты Coursera…), переведены в числа | после удаления «?» все значения числовые |
| 3 | очистка | −999 и 999999 → NaN; −1 → NaN только там, где признак иначе неотрицателен | часы, литры, минуты, навыки 0–10 не бывают −999/−1/999999 |
| 4 | очистка | возраст > 100, рост вне 100–250 см, температура вне 30–45 °C → NaN, строка сохраняется | физически невозможные значения; остальные 997 признаков строки корректны |
| 5 | задание 3 | зарплата: импутация медианой + индикатор salary_missing; жанр: категория «не указано» | медиана устойчива к хвосту; отдельная категория не искажает доли настоящих жанров |
| 6 | задание 3 | недельный сон: линейная интерполяция только внутренних пропусков (limit_area='inside') | соседние дни похожи; края (пн/вс) не экстраполируем — выходные отличаются от будней |
| 7 | задание 4 | аномалии только помечаются (iso_anomaly), не удаляются; зарплата для леса в log10 | необычное ≠ ошибочное; без лога лес реагирует только на зарплату |
| 8 | задание 5 | для зарплаты в описательной статистике — медиана/log1p; редких высоких доходов не удаляем | выбросы зарплаты корректны (старшие специалисты, руководители); удаление занижает среднее и долю высоких доходов |
| 9 | задание 6 | скейлеры и импутация обучены только на train | иначе параметры содержат информацию о test |
| 10 | задание 7 | Box-Cox для строго положительных, Yeo-Johnson для накоплений (есть нули); λ по train | Box-Cox не определён для 0 |
| 11 | задание 8 | жанр — One-Hot с handle_unknown='ignore'; образование — Ordinal (школа<колледж<бакалавриат<магистратура<аспирантура); team_id — frequency encoding по train | жанр номинален; образование упорядочено; ID почти уникальны, One-Hot дал бы сотни разреженных столбцов |
| 12 | задание 9 | «высокий стресс» = stress ≥ 48 (P75 по train) | порог не подсматривает test; предметный порог 60 дал ту же картину |
| 13 | задание 10 | исключены burnout_support_requests_after_6m и career_growth_next_12m | измерены после момента прогноза — утечка из будущего |
