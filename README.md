# Статистические методы и первичный анализ данных

## Практическая работа №8 «Жизнь Айтишника» — вариант М

Первичный анализ синтетического датасета `IT_Life_10000x1000_FINAL.csv` (10 000 айтишников × 1000 признаков).
Вариант — буква **«М»**: ники, начинающиеся на «М» (кириллица) и «M» (латиница), всего **334 строки**.

### Файлы

| Файл | Что внутри |
|---|---|
| `IT_Life_variant_M.ipynb` | Основной ноутбук: код, таблицы, 25 графиков и выводы по заданиям 01–10 |
| `IT_Life_variant_M.docx` | Та же работа в формате Word (отчёт) |
| `decision_log.md` | Журнал решений: что сделано с данными и почему |
| `variant_M_clean.csv` | Очищенные строки варианта (коды пропусков → NaN, невозможные значения → NaN) |
| `variant_M_transformed.csv` | Преобразованные признаки: импутация, log1p, winsorization, кодирование, флаги аномалий |

### Задания

1. Знакомство с данными: отбор варианта, типы признаков, паспорт признаков, шкалы.
2. Пропуски: доли NaN, коды отсутствия (`?`, `-999`, `999999` …), гипотезы MCAR / MAR / MNAR.
3. Импутация: среднее vs медиана, мода vs «не указано», интерполяция недельного сна, missing indicator.
4. Выбросы: IQR, z-score, Isolation Forest; ошибки vs редкие реальные значения.
5. Цена уборки: удаление, winsorization, log1p — что теряется.
6. Масштабирование: StandardScaler, MinMaxScaler, RobustScaler; влияние на KNN.
7. Длинные хвосты: log10-оси, log1p, Box-Cox, Yeo-Johnson.
8. Кодирование категорий: One-Hot, Ordinal, frequency encoding, hashing, новые категории.
9. Корреляции Пирсона и Спирмена, группы по уровню стресса.
10. Модель выгорания: честный Pipeline против утечки данных.

### Как запустить

1. Откройте `IT_Life_variant_M.ipynb` в Jupyter или [Google Colab](https://colab.research.google.com).
2. Положите исходный файл `IT_Life_10000x1000_FINAL.csv` в ту же папку (в Colab — в `/content`).
   Исходный датасет в репозиторий не загружен из-за размера.
3. Выполните все ячейки («Среда выполнения» → «Выполнить все»).

Библиотеки: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scipy`, `scikit-learn`.
Исходный CSV не изменяется; все результаты сохраняются в отдельные файлы. `random_state = 42`.
